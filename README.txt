# VAULT v2.3 更新ファイル

既存の `money` リポジトリに以下3ファイルを上書きしてください。

- index.html
- manifest.webmanifest
- sw.js

## v2.3
- アプリ名を「お金箱」から「VAULT」に変更
- 各操作画面の下部にあった「戻る / キャンセル」ボタンを削除
- 閉じる操作は右上の「×」に統一
- 保存・振り分け・移動などの実行ボタンを横幅いっぱいにして見やすく変更
- v2.2までの自動振り分け編集機能などは維持
- キャッシュをv5へ更新

既存データは引き続き `moneybox-v1` を使うため、残高・履歴は維持されます。
