# VAULT v2.6

今回は「使っていて気持ちいい」方向のアップデートです。

## 追加・改善
- 各お金箱に好きなカラーを設定
  - ホームの残高バーと円グラフにも同じ色を使用
- 各お金箱に任意の「目標額」を設定
  - 例: 趣味 50,000円 / 貯金 100,000円
  - ホームに達成率とプログレスバーを表示
- ホームに「最近の動き」を追加
  - 直近3件の入出金をすぐ確認
- REPORTに「今月の差額」を追加
- REPORTに「いちばん使った箱」を追加
- 円グラフ中央に今月の支出合計を表示
- 見た目の色を、お金箱ごとに一貫するよう改善
- キャッシュをv8へ更新

## 更新方法
既存の money リポジトリへ以下3ファイルを上書き:
- index.html
- manifest.webmanifest
- sw.js

その後 GitHub Desktop で Commit → Push origin。

既存の残高・履歴はそのまま維持されます。
