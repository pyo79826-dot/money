# VAULT v2.4 更新ファイル

既存の `money` リポジトリに以下3ファイルを上書きしてください。

- index.html
- manifest.webmanifest
- sw.js

## v2.4
- 「集計」タブを追加
- 今月の収入 / 支出を表示
- 今月使った金額を用途別の円グラフで表示
- アプリ内カレンダーを追加
  - 日ごとの入金 / 支出を表示
  - 日付をタップすると、その日の入出金を一覧表示
- 自動振り分けした給料は履歴に1件だけ表示
  - 例: 「給料（自動振り分け） +¥60,000」
  - 内訳として「趣味 ¥15,000 / 親孝行 ¥6,000 / 貯金 ¥39,000」などを表示
- 旧バージョンで自動振り分けが複数行に分かれていた履歴も、近い時刻のものを自動で1件にまとめる移行処理を追加
- キャッシュをv6へ更新

※ 「カレンダー連携」は、今回はiPhoneの標準カレンダーへ予定を書き込むのではなく、
VAULT内の入出金カレンダーとして実装しています。
