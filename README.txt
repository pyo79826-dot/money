# お金箱 v2.1 更新ファイル

既存の `money` リポジトリに以下3ファイルを上書きしてください。

- index.html
- manifest.webmanifest
- sw.js

## v2.1
- 各操作画面に「×」戻るボタンを追加
- iPhoneの戻る操作 / スワイプバックで、開いている操作画面を閉じられるように改善
- 下部タブも履歴を持つため、戻る操作で前の画面へ戻れるように改善
- 「給料を振り分け」画面の中で、趣味・親孝行・貯金など各お金箱の振り分け率を直接変更可能
- 振り分け画面で変更した割合はそのまま次回以降の設定として保存
- 振り分け率の合計100%チェックをその場で表示
- キャッシュをv3へ更新

既存の残高・履歴は `moneybox-v1` の保存領域をそのまま使うため維持されます。
